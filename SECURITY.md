# Security policy

## Reporting

Use GitHub private vulnerability reporting. Include a synthetic contract,
workspace layout, expected boundary, observed behavior, and affected commit.

Do not attach production evidence, credentials, internal hostnames, or customer
data.

## Scope reminder

Tuntas reduces false completion claims but is not a process sandbox or signing
authority. Read [the security model](docs/SECURITY-MODEL.md) before using command
or network probes.
